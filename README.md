# 两汉墨记

介绍两汉文化的静态站点。宣纸水墨版式，七卷分章，没有账号。

线上：https://hellodiyuan.xin

## 本地预览

```bash
npm install
npm run dev
```

浏览器打开终端里的地址，一般是 `http://127.0.0.1:5173`。

## 页面

- `index.html` 总览
- `zhidu.html` 制度
- `sixiang.html` 思想
- `tianxia.html` 天下
- `wenyi.html` 文艺
- `riyong.html` 日用
- `baigong.html` 百工
- `kaogu.html` 考古

推到 `main` 后，GitHub Actions 会构建 `dist` 并发布。
